## For future agent

Per-day operation log for `mai-vault`, 2026-10-20 (Moscow time). One operation: the daily currency digest arrived with its tables rendered as raw pipe text, and the cause was fixed at the source rather than in the message.

**12:56** - Digest tables stopped rendering; the blank-line rule fixed

- What: Mai reported that today's digest came without tables ("Sao hôm nay không làm bảng"). The tables were added on 17 October, but a later rewrite of `render_digest` put the separating blank line *after* each table instead of before it, and Telegram only renders a pipe table when the block is separated from the text above and below - so the four blocks arrived as plain `| a | b |` lines.
- Why: the chat message is the only artefact she actually reads; a table that renders as pipes is worse than the bullet list it replaced.
- 🔧 Fix: `currency_rates.py` now emits a blank line both before and after every table, and the trailing `_vault: ...` debug lines were dropped from stderr - the cron terminal merges stderr into the delivered message, so they were duplicating the history footer. Verified against the live digest: 4 tables, 0 unopened, 0 unclosed, stderr empty. The job prompt now also forbids reflowing the tables or dropping empty lines.
